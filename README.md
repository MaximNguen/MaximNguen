## Обо мне

QA-инженер (SDET). Пишу автотесты на **Python**, **TypeScript** и **Go**, тестирую UI и API, выстраиваю проверки в CI/CD. Внутренности бэкенда понимаю достаточно, чтобы тестировать сложные сервисы — с очередями, асинхронностью и базами данных.

- QA и автоматизация сейчас на **AI-ассистенте задач**
- Автотесты: **Playwright (Python + TypeScript), Pytest, Selenium, Allure**
- **Go**: пишу автотесты и разбираюсь в языке
- Понимаю бэкенд: **FastAPI, PostgreSQL, Redis, Kafka, Celery** — проверяю не только по чек-листу, но и по коду
- Процессы: **Jira, Confluence, Bitbucket, GitLab, GitLab CI/CD, GitHub Actions**
